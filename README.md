# Python Data Processing

## Project Overview

This project processes a collection of structured student records and generates useful summary statistics using Python.

It demonstrates how Python can organize records, calculate numerical statistics, summarize categories, identify top-performing students, and filter data.

## Objectives

- Process structured records using Python.
- Calculate summary statistics.
- Use functions for repeated operations.
- Generate examples of processed records.
- Understand basic data-processing techniques.

## Features

- Display student records in a table.
- Calculate total, average, median, minimum, maximum, and range.
- Generate age and marks statistics.
- Count students in each department.
- Identify the top three students.
- Filter students who score at least 80.
- Display an overall summary.

## Dataset

The program uses eight fictional student records with these fields:

- Student ID
- Name
- Department
- Age
- Marks

## Technologies Used

- Python 3
- `statistics` module
- `collections.Counter`
- Lists and dictionaries
- Functions and list comprehensions
- Visual Studio Code
- GitHub

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open a terminal.
5. Run:

`python data_processing.py`

On Windows, you can also try:

`py data_processing.py`

No third-party packages are required.
